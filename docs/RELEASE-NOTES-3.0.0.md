Acid 3.0.0: one plugin folder for every MPC, with a new native touchscreen skin.

- New: runs on the MPC Live III and other 64-bit MPCs as well as the Force and other 32-bit models.
- New: native touchscreen skin with six tabs (SEQ A, EDIT A, SEQ B, EDIT B, MOD, GLOBAL), steady Q-Link and touch behaviour.
- Same generator, blend modes, per-step edit and locks as 2.1.
- Install: `...-aarch64.zip` for the Live III and other 64-bit models, `...-armv7.zip` for the Force and other 32-bit models. See INSTALL.txt inside.
